# Security policy

Please report a vulnerability privately to **hello@halvorai.com**, not in a public issue or pull request.

Include what you found, how to reproduce it, and which version or commit you tested. We'll acknowledge your report within 2 business days and keep you updated while we work on a fix. Please give us a reasonable time to fix it before you disclose it publicly.

Never include real API keys, card numbers or personal data in a report. Synthetic examples are enough.
